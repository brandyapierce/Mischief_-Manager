# Ingestion Logs

This directory contains the audit trail for all ingestion runs.

## Log Format

Each run produces a JSON file named `run-<ISO_TIMESTAMP>.json` containing:

```json
{
  "run_id": "uuid",
  "timestamp": "ISO-8601",
  "mode": "dry-run | live",
  "environment": "check if ANTHROPIC_API_KEY was present",
  "files_processed": [
    {
      "source_filename": "example-article.txt",
      "source_path": "raw/example-article.txt",
      "source_checksum": "sha256-hash",
      "prompt_used": "template_id or snippet of prompt",
      "generated_filename": "wiki/example-article.md",
      "generated_checksum": "sha256-hash",
      "action": "created | updated | skipped | error",
      "anthropic_response_meta": {
        "model": "claude-opus | claude-haiku | etc",
        "tokens_in": 123,
        "tokens_out": 456,
        "stop_reason": "end_turn"
      },
      "error_message": "if any"
    }
  ],
  "summary": {
    "total_files_scanned": 1,
    "files_created": 1,
    "files_updated": 0,
    "files_skipped": 0,
    "errors": 0
  }
}
```

## Purpose

- **Audit trail**: Track every ingestion run with timestamps and checksums
- **Error tracking**: Record any failures or retries for investigation
- **Provenance**: Link generated wiki pages back to source files and processing metadata
- **Learning**: Analyze patterns in run logs to improve the pipeline
- **Secrets protection**: Logs never include ANTHROPIC_API_KEY or other secrets

## Retention

All logs are kept indefinitely to support learning, debugging, and audit compliance.

## Querying Logs

To find all files processed in a specific run:

```bash
cat log/run-2026-09-06T10-30-00Z.json | jq '.files_processed[] | {source_filename, action}'
```

To find all errors across all runs:

```bash
for f in log/run-*.json; do jq '.files_processed[] | select(.error_message != null)' "$f"; done
```

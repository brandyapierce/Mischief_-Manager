# Schema & Templates

This directory contains template definitions and structural guidelines for wiki pages.

## Purpose

Templates define the structure and front-matter fields for wiki pages generated by the ingestion pipeline. They ensure consistency and make pages queryable by the Co-Teacher app.

## Templates

### `entity.md`
Generic template for topics, concepts, entities, or procedures that don't fit zone or checklist patterns.

**Front-matter fields:**
- `title`: Entity name
- `tags`: Array of categorization tags
- `summary`: One-line summary
- `source_file`: Source raw file (populated by ingestion)
- `generated_at`: ISO timestamp of generation

### `zone.md`
Template for physical or organizational zones requiring monitoring and checklists (Bird Building, Garage, Pasture, etc.).

**Front-matter fields:**
- `zone`: Zone name (required)
- `assigned_to`: Current caretaker/owner
- `last_checked`: ISO timestamp of last check-in
- `status`: active | inactive | under_maintenance | archived
- `stale_warning_threshold_minutes`: Minutes before zone is considered stale (default 480 = 8 hours)
- `approval_needed`: Boolean; true if pending trainee approval
- `source_file`: Source raw file (populated by ingestion)
- `generated_at`: ISO timestamp of generation

### `checklist.md`
Template for task checklists tied to zones or processes.

**Front-matter fields:**
- `checklist_for_zone`: Zone this checklist applies to
- `checklist_id`: Unique identifier
- `created_at`: ISO timestamp
- `last_updated`: ISO timestamp
- `created_by`: User who created it
- `source_file`: Source raw file (populated by ingestion)

## Using Templates

1. Copy the appropriate template for your content type
2. Populate front-matter fields
3. Replace placeholder sections with real content
4. Preserve the YAML front-matter structure
5. Ensure section headings match template (required for Co-Teacher parsing)

## Schema Evolution

- New template versions will be tracked in version control
- Legacy templates will remain available in `archive/` if renamed
- Changes to front-matter fields must be documented here
